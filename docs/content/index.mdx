![tDB banner](/assets/tDB/banner.jpg)

tDB answers every oxmysql export, translates MySQL SQL to SQLite as it goes, and runs an
embedded [PocketBase](https://pocketbase.io/) underneath. No MySQL to install, no connection
string, no port to open, nothing to keep running alongside it.

```lua
-- Existing oxmysql code. Unchanged.
local row = exports.oxmysql:single_async('SELECT * FROM players WHERE citizenid = ?', { cid })
```

## What it is not

- **Not a MySQL server.** SQL is translated to SQLite, and a few constructs are refused —
  see [MySQL compatibility](/docs/tDB/mysql-compatibility).
- **Not a drop-in for a database you already have data in.** tDB starts empty; moving an
  existing MySQL database across is a migration, not a swap.
- **Not something to run next to oxmysql.** Remove oxmysql.

## Requirements

| Requirement | Detail |
| --- | --- |
| tLib | **v1.0 or later.** tDB declares `tlib_min_version '1.0'` and will not start without it |
| Platform | **Windows or Linux, x86-64.** The bundled PocketBase builds are `windows_amd64` and `linux_amd64`; there is no ARM build |
| FiveM artifact | New enough for Node 22, which the manifest declares as `node_version '22'` |
| Framework | None |
| OneSync | Not required |
