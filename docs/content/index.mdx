tDB gives your server a database without a database server. It answers every
oxmysql export, translates MySQL SQL to SQLite as it goes, and runs an embedded
[PocketBase](https://pocketbase.io/) underneath. There's no MySQL to install, no
connection string, and nothing to keep running alongside it.

```lua
-- Existing oxmysql code. Unchanged.
local row = exports.oxmysql:single_async('SELECT * FROM players WHERE citizenid = ?', { cid })
```

## What it is not

- **Not a MySQL server.** SQL is translated to SQLite. Most of what FiveM
  scripts write translates cleanly; the rest is refused by name rather than
  quietly changed. See [MySQL compatibility](/docs/tDB/mysql-compatibility).
- **Not a drop-in for a database you already have data in.** tDB starts empty.
  Moving an existing MySQL database across is a migration, not a swap.
- **Not something to run next to oxmysql.** Two resources answering the same
  export name is ambiguous, and they point at two different databases.

## Requirements

| Requirement | Detail |
| --- | --- |
| tLib | **v1.0 or later.** tDB declares `tlib_min_version '1.0'` and won't start without it |
| Platform | **Windows or Linux, x86-64.** The bundled PocketBase builds are `windows_amd64` and `linux_amd64`; there is no ARM build |
| FiveM artifact | New enough to provide Node 22, which the manifest declares as `node_version '22'` |
| Framework | None. tDB is a database, not a framework layer |
| OneSync | Not required |
